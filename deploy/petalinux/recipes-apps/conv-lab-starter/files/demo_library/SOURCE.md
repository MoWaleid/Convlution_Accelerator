# CIFAR-10 demo-library source

These 50 PNGs are official CIFAR-10 page samples 1-5 for each of the ten classes. The catalog records the source URL and SHA-256 of every file. Cite Alex Krizhevsky, *Learning Multiple Layers of Features from Tiny Images* (2009).
