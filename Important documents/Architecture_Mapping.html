Architecture Decision Mapping

This document maps the complete list of 17 recommended architecture decisions from the CNN_Accelerator_Spec_Decisions.pdf specification to the current VHDL implementation in the project.

Summary

The current RTL implementation closely follows the recommendations outlined in the specification document for all of the modules built so far. Notably, the hardware achieves zero BRAM usage for line buffers by correctly utilizing SRL primitives. It also incorporates all mandatory runtime programmability requirements (per-channel rescale shifts and ReLU enables) over a standard AXI4-Lite interface. Furthermore, the design pushes performance beyond the baseline target by implementing 16 parallel output channels (K=16) instead of the requested 4.

Note: The core MAC array (Compute Topology, Multipliers, Pipelining, Rounding, Overflow Handling), Top-Level Data Interfaces (AXI-Stream), and PS Software Stack are currently marked as pending as they have not yet been implemented in the source files. The Golden Model scripts already implement the correct Rounding and Saturation logic pending RTL integration.
